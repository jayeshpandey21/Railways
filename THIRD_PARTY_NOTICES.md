# Third-party data

Train and station directory data can be imported from
[Indian-Railway-Data](https://github.com/prasenjit-27/Indian-Railway-Data),
revision `1dc0ddbc6a06b09ef69d4825ff3127c1f29640fa`, under the MIT License.
The data is downloaded only when `npm run data:import` is run; the large
train schedule file is not bundled with this application.
